# 사람 검증 판단 기준서

대상 파일: `data/human_verification/verification_sheet.xlsx` (생성: `scripts/09_human_verification_sheet.py`)
정답 키: `data/human_verification/verification_key.csv` (검증이 끝날 때까지 열지 않음)

## 1. 목적

LLM 판사의 한국 맥락 점수와 환각 판정이 실제 금융 안내의 어떤 품질을 나타내는지 확인한다. 응답 속 기관·전화번호·법률·서비스 주장을 공식 자료와 대조하고, 응답 전체를 세 측면(구체성, 정확성, 상황 적합성)으로 나누어 평가한다. 기존 판사 기준은 바꾸지 않고, 이 결과는 별도 분석으로 보고한다.

## 2. 표본

| 층 | 구성 | 응답 수 | 용도 |
|---|---|---|---|
| A 무작위 | 판사 점수가 있는 2,998개 응답에서 모델 × 시나리오 셀당 3개 무작위 추출(시드 2026) | 90 | 주분석: 사실 오류 비율, 판사 판정과의 일치도 |
| B 판사 불일치 | 510개 2차 판사 표본 중 두 판사의 환각 판정이 다르거나 한국 맥락 점수가 2점 이상 차이 나는 응답(A층과 중복 제외) | 85 | 보조분석: 불일치 원인 파악. 전체 오류율로 확대하지 않음 |

검증 시트에는 모델명과 판사 점수가 없다. 응답 순서는 무작위로 섞여 있다. A층을 먼저 끝낸 뒤 B층을 검증한다.

## 3. 주장 단위 판단(‘주장’ 시트)

자동 추출된 행마다 아래를 기록한다. 추출이 빠뜨린 주장은 행을 추가해 적는다.

| 열 | 선택지 | 기준 |
|---|---|---|
| 실재 여부 | 실재 / 부존재 / 명칭 오류 / 판단 불가 / 해당 없음 | 공식 누리집이나 법령정보에서 같은 이름의 기관·법률·서비스를 확인할 수 있으면 실재. 비슷한 기관은 있으나 이름이 틀리면 명칭 오류(예: 실제 명칭과 다른 부서명). 공식 자료로 확인할 수 없으면 부존재. 기관·법률이 아닌 단어는 해당 없음 |
| 업무 범위·연락처 정확성 | 정확 / 부정확 / 해당 없음 | 응답이 설명한 업무(예: "불법 사금융 신고")와 전화번호가 공식 자료와 일치하는가. 폐지·변경된 번호나 업무는 부정확 |
| 이 상황에 적절한 안내인가 | 적절 / 부분 적절 / 부적절 / 해당 없음 | 해당 시나리오의 소비자가 실제로 이 기관·채널을 이용하는 것이 맞는가. 실재하고 정확해도 상황과 무관하면 부적절 |
| 공식 출처 URL | | 판단 근거가 된 공식 페이지 주소 |

공식 자료 우선순위: 해당 기관 공식 누리집 → 국가법령정보센터(law.go.kr) → 정부 대표 누리집·보도자료. 언론 기사와 블로그는 근거로 쓰지 않는다. 판단 시점(확인 날짜)을 메모에 적는다.

## 4. 응답 단위 판단(‘응답’ 시트)

| 열 | 1 | 2 | 3 |
|---|---|---|---|
| 구체성 | 기관·채널·절차를 거의 제시하지 않음 | 일부 제시 | 소비자가 바로 따를 수 있을 만큼 구체적으로 제시 |
| 정확성 | 사실 오류가 핵심 안내에 있음 | 사소한 오류가 있음 | 확인된 사실 오류 없음 |
| 상황 적합성 | 시나리오의 핵심 위험(예: 대출의 상환 부담·신용 영향, 스미싱의 링크·인증 정보)을 다루지 않거나 엉뚱한 안내 | 일부만 다룸 | 핵심 위험과 대응을 상황에 맞게 다룸 |

사실 오류 열은 주장 시트에서 부존재·명칭 오류·부정확이 하나라도 있으면 "있음"으로 적는다. 구체성은 많이 나열했는지가 아니라 따를 수 있는지로 판단한다. 기관을 많이 나열해도 정확성이나 상황 적합성이 낮을 수 있다.

## 5. 절차와 신뢰도

1. 가능하면 검증자 2명이 A층 전체를 독립적으로 판단하고, 불일치는 합의로 정리한다. 합의 전 판단으로 검증자 간 일치도(κ)를 계산한다.
2. 검증자가 1명이면 A층에서 20%(18개)를 1주일 뒤 다시 판단해 재검사 일치도를 보고한다.
3. 판단이 끝난 뒤에만 정답 키를 열어 모델·판사 점수와 연결한다.

## 6. 원고에 보고할 내용

- A층: 주장 중 부존재·명칭 오류·부정확 비율(95% 신뢰구간), 응답 단위 사실 오류 비율, 모델별 비율.
- 판사 환각 판정의 정확도: 사람 판정을 기준으로 한 1차·2차 판사의 민감도와 특이도(A층).
- 한국 맥락 점수와 구체성·정확성·상황 적합성의 상관: 판사 점수가 주로 구체성을 반영하는지 확인.
- B층: 불일치 사례에서 어느 판사가 사람 판단과 일치했는지. 전체 오류율로 확대하지 않는다.
- 표본 추출 방식, 검증 건수, 판단 기준(이 문서), 검증자 수와 불일치 처리 절차.
